How it works

A voice activity detector (Silero VAD) listens to the microphone in 32 ms frames. After 160 ms of silence it starts transcribing speculatively; if the silence reaches 500 ms, that's the end of your turn and the transcript is usually already done. If you start talking again before the agent makes a sound, it treats the pause as mid-sentence and merges both parts.

Speech recognition is Parakeet, a transducer model whose encoder weights are all −1, 0 or +1. The encoder runs on the GPU through WebGPU; the token-and-duration decoding loop is hand-written and runs on the CPU in ONNX Runtime Web. The text goes to a small language model on the GPU that streams tokens, and as soon as the first sentence (or a long first clause) is complete, Kokoro synthesizes it while the model keeps writing the rest.

  • Speech to text: NVIDIA Parakeet TDT 0.6B v3 → Moondream Parakeet Redux → ONNX export (CC BY 4.0)
  • Language model: Liquid AI LFM2 or Alibaba Qwen2.5, via Transformers.js
  • Text to speech: Kokoro 82M (Apache 2.0) via kokoro-js
  • Voice activity detection: Silero VAD (MIT) · Runtime: ONNX Runtime Web
