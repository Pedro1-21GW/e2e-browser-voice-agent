Browser voice agent lab

Can a voice agent (listen, think, speak) run entirely inside a browser tab, fast enough to hold a conversation? Each question below is a hypothesis with a working build and measurements.

H1 · confirmed with WebGPU

Can a single HTML file, using existing browser ML libraries and the browser cache, make a voice agent with low latency?

Yes on a GPU: 1.4–2.1 s from the end of your speech to the agent's first sound, on a laptop with a GTX 1050. Without WebGPU it still works, but takes 12–18 s.
