Browser voice agent lab

Voice AI under hardware constraints

Can a voice agent that listens, thinks and speaks run (almost) entirely inside a browser tab, fast enough to hold a conversation? Each question below is a hypothesis with a working build, measurements and a verdict.

Hypotheses

H1 · confirmed with WebGPU

Can a single HTML file, using existing browser ML libraries and the browser cache, make a voice agent with low latency?

Yes on a GPU: 1.4–2.1 s from the end of your speech to the agent's first sound, on a laptop with a GTX 1050 notebook GPU. Without WebGPU it still works, but takes 12–18 s.

H2 · in progress

Can we write the inference engine ourselves and still run it all in one HTML file?

Replacing the libraries with hand-written WebGPU kernels, one piece at a time, checked for correctness against a reference and for speed against H1. The first kernels are correct; the fastest reaches 60% of the GPU's memory bandwidth.
